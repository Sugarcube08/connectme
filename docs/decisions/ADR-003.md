# ADR-003: PostgreSQL and Prisma ORM

## Status
Accepted

## Context
Raw SQL strings scattered across application files lack compile-time type verification and can lead to runtime schema drift. Connect Me needs type-safe queries, relational integrity, transactional rollback, and schema modeling.

## Decision
Use Prisma ORM connected to PostgreSQL:
- Declarative models in `packages/database/prisma/schema.prisma`.
- Fully typed client generated into `@connectme/database`.
- Explicit transactions (`prisma.$transaction`) for single-use code redemption and first-time admin bootstrap.

## Consequences
- Compile-time safety across repository layers.
- Seamless schema management without raw SQL typos.

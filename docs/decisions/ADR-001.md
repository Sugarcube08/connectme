# ADR-001: Monorepo and Workspace Structure

## Status
Accepted

## Context
Connect Me consists of an Express REST API backend, a Next.js App Router web application, a React Native / Expo mobile application, and shared utilities (contracts, validation, design tokens, typed API client, and database ORM). We need a single Git repository with clear architectural boundaries that allows independent builds, shared types, and no leaky abstractions.

## Decision
Adopt a pnpm workspace and Turborepo monorepo structure:
- `apps/api`: Express.js MVC backend.
- `apps/web`: Next.js web application (visitor contact form and web admin dashboard).
- `apps/mobile`: React Native / Expo admin application.
- `packages/database`: Prisma ORM schema, migrations, and database client.
- `packages/contracts`: Shared DTOs, interfaces, and enums.
- `packages/validation`: Shared Zod validation schemas.
- `packages/api-client`: Typed HTTP client for web and mobile clients.
- `packages/design-tokens`: Shared brand palette (Obsidian, Royal Violet, Deep Indigo, Warm Ivory, Metallic Gold, Slate).

## Consequences
- Server-side modules (database, secrets, hashing) are isolated from web and mobile bundles.
- Turborepo caches builds and orchestrates task pipelines efficiently.

# ADR-004: Generated and Reviewed Database Migrations

## Status
Accepted

## Context
Manual schema modifications and raw unversioned scripts create drift, unpredictable states, and production deployment errors.

## Decision
Use Prisma Migrate (`prisma migrate dev` for development, `prisma migrate deploy` for production):
- Migrations are generated into `packages/database/prisma/migrations/`.
- Every migration SQL file is committed to Git and reviewed for index efficiency, constraints, and data safety.
- No `prisma db push` in production; no manual unrecorded production ALTER statements.

## Consequences
- Guaranteed reproducibility across local dev, CI tests, and production deployments.
